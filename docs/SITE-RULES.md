## 1. 技术上不能破的线

- **`file://` 双击就能跑**：不许 ES module、不许 `fetch()` 加载资源、不许 CDN。
- **没有运行时构建步骤**：可以**预构建**（esbuild 打成 IIFE，如 `js/sea.bundle.js`），
  但页面加载时不能有编译。
- 原有渲染器只做**移植**不做重写；LITE 档必须保留手绘风格。
- 改动集中在少数文件，`js/sea.bundle.js` / `js/sea-entry.js` / `js/ocean.js` 非必要不碰。
- `js/clouds.js` 必须保持独立文件、文件名不变 —— 它是 `_lab/tools/sync-kernel.mjs` 的注入目标
  （页面已不加载它，但不要删、不要改名；见 `HANDOFF.md`）。

## 2. 画质两档（2026-10-21 重定义）

| 档 | 风格 | 实现 | 定位 |
|---|---|---|---|
| **FULL** | **无云的海与天** —— 靠光取胜：日出日落时刻、色温、太阳高度真实连续，光景丰富、过渡平滑 | `js/weather.js` 的调色板与 `applySky()` + `css/styles.css` 的 `.atmosphere` / `.sky-wash` / `.celestial` | 默认。**不含云、雨、雷电** |
| **LITE** | **动画电影的一帧** —— 高饱和分层天空 + 大朵积云塔（清晰轮廓、亮边、空气透视），平涂色块，与线稿海同一套语言 | `js/cloud-line.js`（规划中，**暂停**） | 与 FULL **同级**的另一套完整画面 |

- 界面**不允许**出现「云量 / 雨 / 雷电」滑杆，也不再有 TIME 滑杆；**连整块顶部 WEATHER 控件
  都已删除**（2026-10-23 用户两次要求：先删 TIME 滑杆，再删「这个图片里面的这个按钮」）。
  页面右上角不再有时钟、不再有 AUTO / RESET，改时间只剩「拖日月 / 双击日月」两条路。
- **LITE 不是「性能降级的 FULL」**，是另一条美术路线。禁止用「把 scale 调到 0.5」冒充 LITE。
- **FULL 也不做云**：不要因为「天空空」就偷偷把云加回来。
- 云的具体风格规格见 `TODO.md` §3；实验室冻结约定见 `TODO.md` §4。

## 3. 日月与时间（2026-10-23 用户定稿的行为）

- 时间自动流动，**5 秒 = 1 小时**（`SECONDS_PER_HOUR`，`js/weather.js:20`），2 分钟一昼夜。
- **日月同向，都是从右缘升起、往左缘落下**：屏幕**右缘 = 东、左缘 = 西**（2026-10-23 用户定稿，
  此前方向是反的）。月亮不因为「反日」倒着走：满月只是与太阳相隔 12 小时，太阳在左缘落下时
  它才刚从右缘升起。弧线 `x = 50 + 38·cos(theta)`：theta=0 → 88%（右缘），theta=π → 12%（左缘）。
- 日月共用一个 DOM 元素，`rawElev = -0.5` 那一刻 x 从 12% 跳到 88%（太阳在左缘落下、月亮在
  右缘升起）；两侧都淡到 0 才看不见：光球 2° / 2.5°，天光 6°。
- **拖动日月 = 改时间**，跟手 1:1（`applyDrag` 直接写 `timeOfDay`，不等 `update()` 里的 damp），
  反解 `u = acos(cx)/π`；垂直坐标不参与 —— 时刻定了高度就定了，日盘永远贴在自己的弧线上。
- **双击日月 = 切换昼夜**，但**不是原地换一张图**：时针快进，12 小时摊在 1 秒里走完
  （`WARP_HOURS_PER_SEC = 12`，`state.warpHours` 每帧递减到 0），于是太阳真的滑到左缘落下、
  月亮从右缘升起，最后停在对方刚才待的位置上（`toggleDayNight()` 只写 `warpHours += 12`，
  并清掉 `env.lastNow` —— 两次点击之间那 100~350 ms 是手速，不能乘 12 倍）。连按两次攒成
  24 小时，只往前、不倒退。触屏双点同效，键盘 Enter/Space 也走这条。判定是 `pointerup` 自己数的：
  350 ms / 28 px 以内第二次点击。**单击什么都不做**。
- **松手 / 切换之后时间必须继续走**：`finish()` 末尾无条件 `manualTime = false` + `autoTime = true`。
  （2026-10-23 修的 bug：拖完日月之后时间就停住不走。）
- **日月不许「一顿一顿往前跳」**（2026-10-23 用户第三条反馈）：时针按真实经过时间推进
  （`clockDt`，不吃 `js/app.js` 夹在 0.05 s 的那个 `dt`；只对切走标签页的超长空档设 0.25 s 上限），
  **位移只走 `translate`**（2026-10-24）：`.celestial` 的 `left/top` 归零，`applySun` 每帧把
  `state.sunX/sunY × viewport` 写成 px 的 `el.style.translate`（合成器浮点，亚像素连续，不会被吸
  到整像素）。**不要给位移加任何过渡** —— 拖动要 1:1 跟手、快进要 1 秒走完半天，过渡只会把两者
  都拖成「一顿一顿」；夜里那条波光也不许再补 CSS 假光层。
- **顶部 WEATHER 控件（药丸 + AUTO / RESET 面板）已整块删除**（2026-10-23）：`initPanel()` /
  `syncPanel()` / `timeLabel()` / `conditionLabel()` 连同 `#weatherBar` 的 HTML 与 CSS 一并没了
  （静态断言 `_wip/verify/ui_static.mjs`）。想把表冻在某一刻只剩开发者后门 `?t=<hour>`
  （截图对照用；带参数会停在那一刻，要恢复流动得重开一个不带 `?t=` 的地址）。
