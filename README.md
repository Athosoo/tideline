# TIDELINE · Between the Tides

一个环形无尽的海上明信片长廊：一直向前滚动，走到尽头会无缝回到开头。

## 打开方式

- 直接双击 `index.html` 即可。字体、图片和样式都已本地化，不联网也能看到完整效果。
- 如果希望通过本地服务器预览：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 交互

- **滚动 / 触控滑动**：封面线条展开，双扇门向两侧打开，进入海上明信片长廊；继续滚动，镜头沿水平方向漂移。长廊是环形的——滚到最后一张之后会无缝回到第一张，可以一直看下去。
- **两头都合成环**：向前滚会无缝接回第一张；**往回滚也一样**——镜头会绕到上一圈的末尾继续漂，左右两个方向都不会撞墙、不会停死。位移周期正好等于一圈的长度，所以回头的那一帧画面和继续向前看的画面完全一致，看不出接缝。
- **向左 / 向右滑动**：触控板横向两指滑动、或手指在画面上横拖，和上下滚动一样驱动长廊——向左滑＝往前漂，向右滑＝往后退，一样会绕成环；在封面时横向一推也能把门推开。这一路也会拦下浏览器的"后退/前进"手势，所以不会一滑就把页面翻走。垂直或斜向的滑动仍然是原来的页面滚动。
- **这是一扇单向门**：门打开之后再怎么往回滚，长廊都只会绕着环走，永远不会把门关上。想回到封面只有一条路——点左上角的 `TIDELINE` 品牌按钮（镜头沿原路退回，门重新合上）。
- **点击 / 轻点明信片**：卡片会轻微摇晃并飞到面前，左右信息随之切换。
- **横版卡（landscape）**：在长廊里和别的卡一样竖着摆放（整张卡是竖的，画面内容在卡内旋转 90°）；点开放大时，整张卡（卡框 + 画面）作为**刚体一起旋转 90°**——卡框不拉伸变形、画面也不在框内自转，正面和背面都是横向阅读。
- **点击 / 轻点前方的卡片**：在正面和背面之间翻转。
- **点击卡片外 / 按 Esc / 点右上角关闭**：卡片会沿原空间轨迹飞回原处；长廊、海面与另一张卡始终留在原位，不切页、不缩放。
- **SHUFFLE**：重新生成卡片的漂浮位置与倾斜角度（每次刷新也会随机）。
- 支持键盘：`Tab` 聚焦，`Enter` / `Space` 打开和翻面，`Esc` 退出。
- **改变窗口大小**：正在手里的那张卡不会被丢掉——会按新的视口重新量一次尺寸，姿态保持不变（进出全屏、拖动窗口都适用）。
- **放大看卡片时背景继续动**：海面、云、雨、雷电、光照都照常运行，只是镜头停在原地（卡片飞回去时不会错位）。

## 天气与时间

页面会自动读取**本机时间**，并尝试读取**实时天气**（Open-Meteo，免费、无需 API key），然后把它们变成一组**连续的状态场**，而不是几套预设贴图。

**太阳 / 月亮**

- **拖动**：拖动日月盘就是改时刻，跟手 1:1。两只盘子都是**右缘升起、左缘落下**（屏幕右 = 东、左 = 西），
  光影、天空、海面反射都会自然跟随。**松手之后时间继续自动流动**，不需要再按一次 AUTO。
- **双击**：在白天和夜晚之间切换（白天 → 午夜 0 点，夜里 → 正午 12 点），切完照常流动。
  **单击不做任何事** —— 免得手一抖就把表挪走。
- 太阳高度穿过地平线时，太阳盘会自然变成月亮盘，并带有月相阴影。

**顶部 WEATHER 面板**

| 按钮 | 作用 |
| --- | --- |
| AUTO | 时间继续自动流动（5 秒 = 1 小时） |
| RESET | 回到此刻的真实时间，并继续自动流动 |

云量 / 风雨 / 雷电滑块不是「暂时藏起来」而是**不做**（FULL 档就是一片没有云的海）；
TIME 滑块在 2026-10-23 按用户要求删除，改时间只走「拖日月 / 双击日月」两条路。
面板上的状态文字会显示天气来源（`LIVE` / `CLIMATE`）、当前时刻和晴/夜。

**天气来源与降级**

- 有网络时优先用 Open-Meteo 的云量、风速、降水、天气代码；结果缓存在 `localStorage`，15 分钟内不重复请求。
- 请求失败、离线或 `file://` 被浏览器拦截时，自动退化为 **CLIMATE**：按日期做种子生成一条确定但每天不同的连续曲线。
- 拖动日月期间时刻由手指接管，**松手立刻交还给自动流动**；后台天气只改风，不会再覆盖时刻。

**海面与光影**

- 海面是多层方向性涌浪：远处浪小、密、快，近处浪高、长、慢，形成强纵深；风让浪向顺风偏转，雨增加高频碎浪和雨圈，风暴叠加白沫与短浪。
- 太阳/月亮在水面的反射柱会跟着方位移动；夜里变成冷色窄反射。
- 云量降低水面高光与环境亮度；雷电会短暂照亮云层、天空和海面。
- 天空渐变、海面颜色、卡片光角、环境明暗都来自同一组 CSS 变量，所以昼夜与天气是连续的。

**极简模式**：云层帧率/分辨率/FBM octave、雨粒子数量都读取同一套 `quality` 预算；LITE 下云更少、更糊、雨滴更少，但光影和交互仍在。

**可调项**：默认坐标在 `js/weather.js` 顶部（`state.latitude`，以及请求里的经度）；想换城市改这两处即可。天气请求只读取天气，不发送任何用户数据。

## 沉浸模式（IMMERSIVE）

点右上角 `IMMERSIVE` 按钮，或按 `F` 键，界面「熄灯」：

- 藏起来的是所有*解释界面*的东西——页眉（品牌、`SHUFFLE`、模式开关、计数）、`WEATHER` 面板、进度轨、`SCROLL TO WANDER`、场景标注、`TAP TO PICK UP`、`LET THE WATER LEAD THE WAY`、封面上的页眉与坐标，放大后视窗里的关闭按钮、`FRONT · BACK` 指示器、`CLICK CARD TO TURN`、`CLICK OUTSIDE TO RELEASE`，以及自定义光标（同时恢复系统指针）。
- 留下的是所有*属于内容*的东西——当前卡片编号 / 标题 / 副标题、放大后的标题、日期、引文与译文、`POSTCARD Nº` 落款、卡片正反面、海面、天空与云雨。
- 进入时同步请求浏览器全屏；从浏览器全屏退出（`Esc` 或浏览器自己的退出）时，沉浸模式也会一起退出，两者始终同进同出。不支持全屏的环境（部分 Safari、个别 `file://` 宿主）只做视觉部分，不影响使用。
- 退出方式：移动鼠标或触屏 → 右上角浮出 `EXIT IMMERSIVE` 胶囊按钮（2.6 秒无操作后自动淡出）；或按 `Esc`；或再按一次 `F`。
- 选择会记在 `localStorage`（`tideline.immersive.v1`），下次打开保持。

## 海面（open-sea 渲染器 · 直接搬）

海面用的是 [open-sea-skin](https://github.com/d-dev0101/open-sea-skin) 的**原版渲染器**，不是仿写：

- `js/sea.bundle.js`（771 KB，esbuild 把它的 `ocean.js` + `three.webgpu.js` / `three.tsl.js` / `three.core.js` / `BloomNode.js` 打成一个 **classic script**，所以 `file://` 双击可用、无运行时 CDN、无构建步骤）。里面的 Gerstner 五波、解析法线、FBM 细节、Fresnel、太阳高光、浪尖泡沫、地平线雾、ACES + bloom 后处理、5.5 m 相机 / 55° 镜头 / 26% 地平线，全部是它的原样。
- 天空也由它画（球顶 + 同一个解析天空函数），所以海天之间没有接缝；CSS 里原来那层渐变天空（`.sky-wash` / `.light-glow`）在它启用时自动让位，地平线亮线、日/月盘、云、雨、雷电、颗粒、暗角仍然是我们自己的图层。
- **调色板用的也是它的表**（DAY / DUSK，加一组夜/风暴变体），由 `js/weather.js` 的日照高度、云量、风暴强度插值——它的海之所以有立体感，靠的就是"深蓝天空反射亮地平线"这个梯度，换成我们原来的奶油色天空，浪会立刻摊平成一张纸。
- **风雨对海面的作用**：`seaState` 直接驱动浪高（`0.25 + sea*1.5`，与引擎 demo 的滑杆同一条映射）；云量与风暴暗化天空并压低阳光；雷电让整片水面一起亮；太阳/月亮的方向跟着你拖动的那颗日/月盘走（方位取自盘子的屏幕 x，高度做了抬升，免得永远是一道夕阳长光）。
- **云**：引擎的天空里加了一层真正的云盖（`js/sea-entry.js` 的 `skyColor`），原版只有贴着地平线的一条低云带。现在云盖覆盖地平线以上的整片天空：两层不同速度的 FBM 做视差，云顶受光、云底压暗、迎光侧发亮，风暴时整体压黑、闪电从内部点亮；底部淡出到地平线雾色，所以和海的交界没有硬边。海面反射读的是同一个函数，阴云会一起映在水上。LITE 只保留单层。
- 三级回落：**原版渲染器 → 自写 WebGL2（`js/ocean.js`，`?nogl=1` 可强制）→ Canvas-2D 画法**；引擎初始化期间先用便宜的 2D 海面顶着，就绪后自动换上，失败则保留。引擎接管天空时，2D 云画布（`js/weather.js`，已按新地平线 26% 重排并做底部渐隐）自动让位，它继续负责 LITE 与回落路径的云。

## 海面（自写 WebGL2 回落 · `js/ocean.js`）

海面不是画出来的，是**逐帧算出来的 3D 曲面**（WebGL2，`js/ocean.js`，不依赖任何第三方库，`file://` 直接可用）。波形模型移植自 [open-sea-skin](https://github.com/d-dev0101/open-sea-skin)（MIT）：

- **五个 Gerstner 涌浪**（波长 60 / 31 / 18 / 9.5 / 5 m，陡度 0.12 / 0.12 / 0.09 / 0.07 / 0.05，深水色散 c = √(gk)），在顶点着色器里逐帧位移，浪尖是几何而不是贴图。
- **解析法线**：由波形偏导数取切向量与副切向量叉乘得到，逐像素计算。
- **毛细浪（chop）**：一张烘焙好的无缝 FBM 法线贴图，按三个尺度滚动叠加 —— 两次纹理读取就替代了十几次噪声计算，所以它能铺满整个可见海面。
- **着色**：Fresnel 天空反射、太阳／月亮高光（宽散射 + 近处细闪）、浪尖白冠泡沫、背光浪尖透光、涌浪坡面明暗。
- **调色板与光照全部来自 `js/weather.js`**：`--sky-*` / `--sea-*` / `--sun-*` 以及 `Weather.state`（时间、云量、风、雨、风暴、闪电、日月位置）逐帧同步。拖动太阳，海面的反光带跟着走；入夜自动变成月光海面；打雷时整片水面一起亮。
- **接天**：远处按距离淡出到与 CSS 地平线**同一个颜色**，所以 3D 海面和 CSS 天空无缝相接，看不出接缝。
- **性能**：极坐标网格（近处约 0.3 m 一格，远处一路拉伸到 5 km），细节强度按距离衰减，DPR 上限 1.5，并按实测帧率在 0.62–1.0 之间自动调整渲染分辨率；两个方向都会绕环的长廊与它无关，各走各的。
- **回落**：浏览器没有 WebGL2（或着色器起不来）时，自动回到原来的 2D 绘制海面，功能不受影响；想手动对比可以加 `?nogl=1`。

## 性能与极简模式（LITE）

右上角有一个 `FULL / LITE` 开关：

- **点击**：在完整模式和极简模式之间切换，选择会记在 `localStorage`，下次打开保持。
- **长按约 0.5 秒**：恢复 `AUTO` 自动判断；按钮上出现一个小圆点表示当前是自动模式。

极简模式保留光影和所有场景交互（滚动镜头、卡片漂移/倾斜、放大/翻转、聚焦视窗），只降低渲染开销：

| 项目 | FULL | LITE |
| --- | --- | --- |
| 画布 DPR 上限 | 2 | 1.25 |
| 海面线条 | 52 / 移动端 32 | 28 / 移动端 18 |
| 海面描边层数 | 3 | 2 |
| 海面重绘频率 | 每帧（约 60fps） | 30fps（镜头与卡片仍是 60fps） |
| 水面反光 / 浪花 | 52 / 18 | 18 / 8 |
| 环境浮尘 | 24 / 移动端 14 | 8 / 移动端 4 |
| 卡片阴影、光晕、水影 | 完整 | 减弱 |
| 海面网格（极坐标） | 200 × 200（约 4 万顶点） | 112 × 112（约 1.3 万） |
| 海面细节半径 | 150 m | 70 m |
| 浪尖白冠泡沫 | 开 | 关 |
| 海面噪声阶数 | 3 | 2 |
| 颗粒、等高线、网格、晕影 | 完整 | 减淡 |
| 模糊与部分混合模式 | 完整 | 关闭或简化 |

自动判断（AUTO）：先根据 CPU 核心数、内存、DPR 和分辨率做初判；进入长廊后先预热 1 秒，再实测 2 秒帧率，如果低于约 45fps 就自动切到 LITE。手动选择 FULL 后不会被自动覆盖。后续的天气/云/雨/雷电层会共用同一套 `quality` 预算（`cloudFps / cloudResolution / fbmOctaves` 已经预留），所以一个开关就能降整场渲染。

## 添加新的明信片

1. 把正反面图片放进 `assets/postcards/`。
   - 竖版卡保持 `2:3` 画幅（例如 `03-front.png`、`03-back.png`）。
   - 横版卡保持 `3:2` 画幅（例如 `04-front.png`、`04-back.png`）。
2. 打开 `js/app.js`，在文件顶部的 `POSTCARDS` 数组中追加一项：

```js
{
  number: "03",
  title: "Your Title",
  meta: "2026 · SOMEWHERE BY THE SEA",
  short: "A short line for the footer",
  quote: "“A line that belongs on the card.”",
  quoteCn: "「一句中文小注。」",
  date: "2026",
  accent: "#c96e53",
  pixel: false,                 // 像素图设为 true；高分辨率插画设为 false
  landscape: false,             // 横版卡设为 true（长廊里竖放，放大时转成横版）
  front: "assets/postcards/03-front.png",
  back: "assets/postcards/03-back.png",
}
```

页面会自动生成新卡片、调整环形周期、更新计数并把它加入随机构图。长廊的周期由数组长度推导，所以增加或删除卡片都不需要改滚动逻辑。

> 当前 `01`、`02` 两张原图只有 100×150 / 120×180 像素，因此在 Focus 视窗里会保留明显的像素颗粒。如果之后拿到更高分辨率的母版，把 `pixel` 设为 `false`（或删掉该字段）就能得到更细腻的放大效果。
>
> `04`—`07` 是四张占位卡（SVG，含两张横版）；`03` 已替换为你加入的横版卡（150×100 PNG）。直接替换 `front` / `back` 即可换成正式素材。

## 设计结构

- `index.html`：封面、3D 长廊、聚焦视窗与无障碍结构。
- `css/styles.css`：封面双门、海上光线、卡片实体边缘、聚焦界面与响应式样式。
- `js/app.js`：随机漂浮算法、环形滚动镜头、Canvas 海面、卡片交互和翻转逻辑。
- `js/weather.js`：天气与时间仿真（太阳/月亮位置、云/雨/风暴/雷电、顶部面板、系统时间与 Open-Meteo 读取、离线气候学降级）。
- `assets/fonts/fonts.css`：内嵌字体，保证 `file://` 直接打开时排版完整。
- `assets/postcards/`：明信片素材（`01`、`02` 为原图，`03`—`07` 为占位 SVG）。
- `js/clouds.js`、`js/ocean.js`、`js/sea.bundle.js`、`js/sea-entry.js`：体积云层、自写回落海面、原版海面 bundle 与它的构建源（分别见上文各节）。
- `1/`, `2/`, `3/`：保留在本地的原始素材目录，不影响页面运行；已加入 `.gitignore`，不随仓库发布。

主色板集中在 `css/styles.css` 顶部的 CSS 变量中：深海绿、海水蓝、纸白、沙色和一点珊瑚色。
